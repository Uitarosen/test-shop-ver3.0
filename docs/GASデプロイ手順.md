# 買取フォームの受け口（Google Apps Script）を設定する手順

買取フォームの申込を Google スプレッドシートに記録し、写真を Google ドライブに保存し、通知メールを送る仕組みを作ります。
作業時間はおよそ15分です。Googleアカウント（店舗用のものがおすすめ）でログインした状態で進めてください。

---

## 1. スクリプトを作る

1. ブラウザで <https://script.google.com/> を開く
2. 左上の **「＋ 新しいプロジェクト」** をクリック
3. 左上の「無題のプロジェクト」をクリックし、名前を **「AUGUST SHOP 買取フォーム」** に変更
4. 中央のエディタに最初から書かれている `function myFunction() { … }` をすべて消す
5. このリポジトリの **`gas/Code.gs` の中身をすべてコピー**して貼り付ける
   - GitHub で `gas/Code.gs` を開き、右上のコピーボタン（四角が2つ重なったアイコン）で全体をコピーできます
6. 貼り付けたコードの上の方にある次の行で、通知先メールアドレスを確認する

   ```js
   var NOTIFY_EMAIL = ''; // 通知先（カンマ区切りで複数可）。空欄のまま、スクリプト プロパティ NOTIFY_EMAIL で設定するのがおすすめ
   ```

7. 上部の **💾（プロジェクトを保存）** をクリック

## 2. 初回の準備（シートとフォルダの作成）

1. 上部の関数の選択欄（「実行」ボタンの右）で **`setup`** を選ぶ
2. **「▷ 実行」** をクリック
3. 「承認が必要です」と出たら **「権限を確認」** → 自分のアカウントを選ぶ
4. 「このアプリは Google で確認されていません」と出たら、左下の **「詳細」** → **「AUGUST SHOP 買取フォーム（安全ではないページ）に移動」** → **「許可」**
   - 自分で作ったスクリプトなので問題ありません。スプレッドシート・ドライブ・メール送信の権限を求められます
5. 画面下の「実行ログ」に、作成された **スプレッドシートのURL** と **写真フォルダのURL** が表示されます
   - Google ドライブのマイドライブにも「AUGUST SHOP 買取申込一覧」「AUGUST SHOP 買取フォーム 写真」ができています

### 動作確認（任意）

関数の選択欄で **`testSubmit`** を選んで実行すると、テスト申込が1件シートに記録され、通知メールが届きます。届いたら、シートのテスト行は削除して構いません。

## 3. Webアプリとして公開する

1. 右上の **「デプロイ」** → **「新しいデプロイ」**
2. 「種類の選択」の歯車アイコン → **「ウェブアプリ」**
3. 次のように設定する
   | 項目 | 設定 |
   |---|---|
   | 説明 | 買取フォーム v1（任意） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |
4. **「デプロイ」** をクリック
5. 表示された **「ウェブアプリ」のURL**（`https://script.google.com/macros/s/……/exec`）をコピー

> 「全員」にしても、できるのは「申込を送ること」だけです。シートや写真フォルダは公開されません。

## 4. サイトにURLを設定する

1. GitHub でこのリポジトリの **`assets/js/config.js`** を開き、右上の鉛筆アイコン（Edit this file）をクリック
2. 次の行の `""` の中に、コピーしたURLを貼り付ける

   ```js
   formEndpoint: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

3. 右上の **「Commit changes…」** → **「Commit changes」**
4. 1〜2分後にサイトを開き、買取フォームの下の「※ 現在テスト表示です」が消えていればOK
5. 実際にフォームから1件送信し、シートの記録・写真フォルダ・通知メールを確認する

---

## あとから変更するとき

### 通知先メールアドレスを変える（サイト側の変更は不要）

どちらかの方法で変更できます。

- **かんたん**：Apps Script の画面左の ⚙（プロジェクトの設定）→ 一番下の「スクリプト プロパティ」→ **「スクリプト プロパティを追加」**
  プロパティ `NOTIFY_EMAIL`、値に新しいアドレス（複数ならカンマ区切り）を入れて保存。**再デプロイ不要**で、すぐ反映されます
- **コードで変える**：`Code.gs` の `NOTIFY_EMAIL` を書き換えて保存し、下の「コードを直したとき」の手順で再デプロイ

### コードを直したとき

**「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」**
こうするとURLは変わらないので、サイト側（config.js）の変更は不要です。
※「新しいデプロイ」を作り直すとURLが変わるので注意してください。

### 申込一覧の使い方

- 1申込が1行です。「アイテム詳細」に全アイテムがまとめて入ります
- 最後の「対応状況」列は店舗用のメモ欄です（未対応 → 連絡済み → 査定済み など自由に）
- 新規クーポン（NEW20）の確認は、このシートで **お名前・電話番号を検索**し、過去の申込がないかを見てください

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 送信すると「送信できませんでした」と出る | デプロイの「アクセスできるユーザー」が **全員** か。URLが `/exec` で終わっているか |
| メールが届かない | 迷惑メールフォルダ。NOTIFY_EMAIL の綴り。Apps Script 左メニュー「実行数」にエラーが出ていないか |
| シートに記録されない | Apps Script 左メニュー「実行数」でエラー内容を確認 |
| コードを直したのに反映されない | 「デプロイを管理」で新バージョンを作ったか |

無料のGoogleアカウントでは、通知メールは1日100通までです（通常の運用では問題ありません）。
