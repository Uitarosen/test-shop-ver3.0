# 買取フォームの受け口（Google Apps Script）を設定する手順

買取フォームの申込について、次の4つを自動で行う仕組みを作ります。

- 指定のスプレッドシートに1件1行で記録
- 写真を Google ドライブに保存（申込ごとに `yyyy/MM/dd_お名前さま_受付番号` フォルダ）
- お客様へ自動返信メール（お礼・スタッフから折り返す旨・入力内容）
- 店舗へ通知メール

作業時間はおよそ15分です。**記録先のスプレッドシートを編集できる Google アカウント**でログインした状態で進めてください。
自動返信メールは、このアカウントのアドレスから送信されます。

---

## 1. スクリプトを作る

1. ブラウザで <https://script.google.com/> を開く
2. 左上の **「＋ 新しいプロジェクト」** をクリック
3. 左上の「無題のプロジェクト」をクリックし、名前を **「AUGUST SHOP 買取フォーム」** に変更
4. 中央のエディタに最初から書かれている `function myFunction() { … }` をすべて消す
5. このリポジトリの **`gas/Code.gs` の中身をすべてコピー**して貼り付け、**💾（保存）** をクリック

## 2. スクリプト プロパティを設定する

左の **⚙（プロジェクトの設定）** → 一番下の **「スクリプト プロパティを編集」** → 次を追加して **「スクリプト プロパティを保存」**。

| プロパティ | 値 | 必須 |
|---|---|---|
| `SHEET_ID` | 記録先スプレッドシートのID（URLの `/d/` と `/edit` の間の文字列） | 必須 |
| `NOTIFY_EMAIL` | 店舗側の通知先（カンマ区切りで複数可） | 推奨 |
| `FOLDER_ID` | 写真の保存先フォルダのID（URLの `/folders/` の後ろ）。空なら初回にマイドライブへ「AUGUST SHOP 買取フォーム 写真」を自動作成 | 任意 |
| `SHEET_NAME` | 記録先のシート名。空なら一番左のシート | 任意 |

- シートが空なら、初回の申込時に見出し行が自動で入ります
- メールアドレスやシートIDは公開リポジトリに載せず、ここで設定します

## 3. 初回の実行（権限の承認）

1. エディタ上部の関数の選択欄（「実行」の右）で **`setup`** を選び、**「▷ 実行」**
2. 「承認が必要です」→ **「権限を確認」** → 自分のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、左下の **「詳細」** → **「AUGUST SHOP 買取フォーム（安全ではないページ）に移動」** → **「許可」**
   - 自分で作ったスクリプトなので問題ありません。スプレッドシート・ドライブ・メール送信の権限を求められます
4. 画面下の「実行ログ」に、記録先シート・写真フォルダ・通知先が表示されればOK

### 動作確認（任意）

関数の選択欄で **`testSubmit`** を選んで実行すると、テスト申込（写真1枚つき）が1件処理されます。
シートに1行追加され、写真フォルダができ、`NOTIFY_EMAIL` 宛てに **自動返信メールと店舗通知メールの2通** が届きます。確認後、テスト行とフォルダは削除して構いません。

## 4. Webアプリとして公開する

1. 右上の **「デプロイ」** → **「新しいデプロイ」**
2. 「種類の選択」の歯車アイコン → **「ウェブアプリ」**
3. 次のように設定する
   | 項目 | 設定 |
   |---|---|
   | 説明 | 買取フォーム v1（任意） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |
4. **「デプロイ」** をクリック
5. 表示された **「ウェブアプリ」のURL**（`https://script.google.com/macros/s/……/exec`）をコピー

> 「全員」にしても、できるのは「申込を送ること」だけです。シートや写真フォルダは公開されません。

## 5. サイトにURLを設定する

1. GitHub でこのリポジトリの **`assets/js/config.js`** を開き、右上の鉛筆アイコン（Edit this file）をクリック
2. 次の行の `""` の中に、コピーしたURLを貼り付ける

   ```js
   formEndpoint: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

3. 右上の **「Commit changes…」** → **「Commit changes」**
4. 1〜2分後にサイトを開き、買取フォームの下の「※ 現在テスト表示です」が消えていればOK
5. 実際にフォームから1件送信し、自動返信メール・通知メール・シートの記録・写真フォルダを確認する

## あとから変更するとき

### 通知先・記録先を変える（サイト側の変更は不要）

Apps Script の ⚙（プロジェクトの設定）→「スクリプト プロパティ」で `NOTIFY_EMAIL`・`SHEET_ID`・`FOLDER_ID` を書き換えて保存します。**再デプロイ不要**で、すぐ反映されます。

### 自動返信メールの文面を変える

`Code.gs` の `autoReply_` 関数の中の文章を書き換え、下の「コードを直したとき」の手順で再デプロイします。
お客様が自動返信に返信すると、`NOTIFY_EMAIL` の先頭アドレスに届きます。

### コードを直したとき

**「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」**
こうするとURLは変わらないので、サイト側（config.js）の変更は不要です。
※「新しいデプロイ」を作り直すとURLが変わるので注意してください。

### 申込一覧の使い方

- 1申込が1行です。「アイテム詳細」に全アイテムがまとめて入ります
- 「自動返信」列には、お客様への自動返信を送れたかが入ります（送信済み／送信失敗など）
- 最後の「対応状況」列は店舗用のメモ欄です（未対応 → 連絡済み → 査定済み など自由に）
- 新規クーポン（NEW20）の確認は、このシートで **お名前・電話番号を検索**し、過去の申込がないかを見てください

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 送信すると「送信できませんでした」と出る | デプロイの「アクセスできるユーザー」が **全員** か。URLが `/exec` で終わっているか |
| メールが届かない | 迷惑メールフォルダ。NOTIFY_EMAIL の綴り。シートの「自動返信」列。Apps Script 左メニュー「実行数」にエラーが出ていないか |
| 「SHEET_ID が未設定です」と出る | スクリプト プロパティの `SHEET_ID` を確認 |
| シートに記録されない | Apps Script 左メニュー「実行数」でエラー内容を確認 |
| コードを直したのに反映されない | 「デプロイを管理」で新バージョンを作ったか |

無料のGoogleアカウントでは、送信できるメールは1日100通までです。自動返信と店舗通知で1申込あたり2通使うため、1日およそ50件が上限です。
