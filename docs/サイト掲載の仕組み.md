# 買取実績・クーポンをスプレッドシートから掲載する仕組み

スタッフは、スプレッドシート「AUGUST SHOP サイト掲載データ」と Google フォーム「買取実績の登録」だけでサイトを更新できます。

```
フォーム「買取実績の登録」で登録（写真も）
  → 「実績」シートに1行追加（写真はドライブ。共有は「制限付き」のまま）
  → 「サイトに掲載」にチェック
  → Apps Script（gas/site-sync.gs）が写真を縮小して、掲載する項目だけを Cloudflare に送る
  → サイトの買取実績ページ・トップに表示（およそ1分）
チェックを外す → サイトからデータと写真を削除
```

| 置き場所 | 中身 |
| --- | --- |
| スプレッドシート「サイト掲載データ」 | 実績・クーポンの元データ（メモ・メールアドレスなどはサイトに送らない） |
| Google ドライブ | フォームで登録した写真の元データ（制限付き） |
| Cloudflare（Worker `worker/index.js`） | サイトに出すデータと縮小写真。テストは KV、本番は R2 |
| `data/results.json` / `data/coupons.json` | Cloudflare のデータが無い環境（GitHub Pages・プレビュー）で表示する予備のデータ |

## 1. 初期設定（最初に1回）

### 1-1. 合言葉を作る

Apps Script と Cloudflare だけが知っている、パスワードのような文字列です。**チャットやメールには貼らないでください。**

- Mac：ターミナルを開いて `openssl rand -hex 32` を実行し、表示された64文字をコピー
- または、パスワード管理ソフトの「パスワード生成」で、英数字40文字以上を作る

### 1-2. Cloudflare に合言葉を登録する

1. Cloudflare の管理画面で「Workers & Pages」→ `august-shop-test` を開く
2. 「設定（Settings）」→「変数とシークレット（Variables and Secrets）」→「追加（Add）」
3. 種類は「シークレット（Secret）」、名前は `SYNC_SECRET`、値に合言葉を貼り付けて「デプロイ（Deploy）」

### 1-3. Apps Script を組み込む

1. スプレッドシート「AUGUST SHOP サイト掲載データ」を開き、「拡張機能」→「Apps Script」
2. 左の「ファイル」の「＋」→「スクリプト」で、名前を `site-sync` にする
   - すでにある `コード.gs` などのファイルは消さないでください（買取フォームの受け口が入っている場合があります）。`site-sync` は同じプロジェクトに並べても衝突しないように作ってあります
3. GitHub の `gas/site-sync.gs` の中身をすべて貼り付けて保存（💾）
4. スプレッドシートの画面に戻って再読み込みすると、上のメニューに「サイト掲載」が出ます
5. 「サイト掲載 ＞ 初期設定（最初に1回）」を実行
   - Google の許可画面が出たら、アカウントを選んで許可します（「このアプリは確認されていません」と出たら「詳細」→「〜に移動」）
   - サイトのアドレス（例：`https://august-shop-test.test-shop-ver3.workers.dev`）と、1-1 の合言葉を入力します
6. 初期設定で行われること
   - 「実績」「クーポン」シートの右端に「サイト反映」列を作る（反映の結果が書かれます）
   - 「サイトに掲載」の列全体をチェックボックスにする
   - 「選択肢」シートに「カテゴリー」の列を作る
   - フォームに「カテゴリー」「クーポンを利用した買取ですか？」の質問を追加（写真の質問の前）
   - 反映のきっかけ（チェックの付け外し・フォーム送信・1時間ごと）を登録
   - 1回目の反映

### 1-4. フォームの写真の欄を複数枚にする（画面での操作）

Apps Script では写真の欄の設定を変えられないため、フォームの編集画面で行います。

1. フォーム「買取実績の登録」を開き、「写真」の質問をクリック
2. 「最大ファイル数」を **10** にする（「特定のファイル形式のみ許可」をオンにして「画像」を選ぶのがおすすめ）

## 2. スタッフの使い方（「使い方」シートに貼る文案）

```
■ 買取実績を登録する
1. 「買取実績の登録」フォームを開き、ブランド・アイテム名・サイズ・状態・カテゴリー・クーポン利用・買取金額・買取日・写真（10枚まで）を入れて送信します（スマホ可）。
2. 登録内容は「実績」シートに1行ずつ追加されます。この時点ではまだサイトに出ません。
3. 内容を確認し、「サイトに掲載」にチェックを入れると、1分ほどでサイトに掲載されます。結果は「サイト反映」列に表示されます。

■ 買取実績を直す・取り下げる
・誤字などは「実績」シートのセルを直接直してください。掲載中の行を直すと、自動でサイトにも反映されます。
・サイトから外したいときは「サイトに掲載」のチェックを外します（行は消さないでください）。サイトから写真も消えます。
・写真の1枚目が一覧に表示されます。

■ クーポンを追加する・終える
・「クーポン」シートに1行追加し、「サイトに掲載」にチェックを入れます。クーポンIDは半角英数字（例：NEW20）で、他と重ならないようにします。
・開始日から終了日までの間だけサイトに表示されます。終了日を過ぎると自動で消えるので、終える作業は不要です。
・すぐに止めたいときは「サイトに掲載」のチェックを外します。

■ 状態・カテゴリーの選択肢を増やす・変える
・「選択肢」シートを編集したあと、メニュー「サイト掲載 ＞ 状態・カテゴリーの選択肢をフォームに反映」を実行します。
・カテゴリーを変えたときは、サイトの絞り込みボタンも変える必要があります（担当者に連絡）。

■ うまくいかないとき
・「サイト反映」列に「エラー：…」と出たら、その内容を直すと自動で再反映されます。
・すぐに反映したいときは、メニュー「サイト掲載 ＞ 今すぐ反映」。
・「写真を準備中」は、写真が多いときに出ます。次の反映（1時間以内）で掲載されます。

■ やってはいけないこと
・見出し行（1行目）の名前を変えない／行を削除しない（チェックを外して取り下げる）
・お客様の個人情報（名前・住所・電話番号など）をこのファイルに書かない
```

## 3. 本番で R2 を使う準備（Cloudflare）

テストでは KV に保存しています。本番は、写真を大量に置ける R2 に切り替えます（切り替え時に `worker/index.js` と `wrangler.jsonc` の保存先を変更します）。

### 3-1. R2 を有効にする（支払い方法の登録）

1. Cloudflare の管理画面で、左メニューの「ストレージとデータベース（Storage & Databases）」→「R2 オブジェクトストレージ（R2 Object Storage）」を開く
2. 初めての場合は「R2 を購入（Purchase R2）」または「R2 サブスクリプションを追加」の画面が出るので進む
3. 支払い方法（クレジットカード）と請求先の情報を入力して確定する
   - 料金：毎月 10GB の保存と、一定回数の読み書きまでは無料。配信の通信料はかかりません
   - 10GB を超えた分は 1GB あたり月 0.015 ドル（10GB 超えても月数十円程度）
4. 「概要」に R2 の画面が表示されれば有効化は完了

### 3-2. 写真置き場（バケット）を作る

1. R2 の「バケットを作成（Create bucket）」
2. 名前：`august-shop-media`、場所：「自動（Automatic）」のまま（または「アジア太平洋（APAC）」）
3. 「バケットを作成」。公開設定（Public access）は**オフのまま**で大丈夫です（サイトへの配信は Worker が行います）

### 3-3. 使いすぎの通知を設定する（おすすめ）

1. 右上のアカウント →「通知（Notifications）」→「追加（Add）」
2. 「使用量ベースの請求（Usage Based Billing）」を選び、R2 の保存量などの通知を設定する

> 画面の名前や並びは変わることがあります。見当たらない場合はスクリーンショットを共有してください。

## 4. 仕組みの詳細（保守する人向け）

- `worker/index.js`
  - 公開：`GET /api/results`、`GET /api/coupons`、`GET /media/<名前>.jpg`
  - Apps Script 専用（`Authorization: Bearer <SYNC_SECRET>`）：`GET /api/admin/media`、`PUT /api/admin/media/<名前>`、`POST /api/admin/sync`
  - 合言葉が未設定・32文字未満のときは管理用の受け口をすべて止める。送られた画像は JPEG/PNG/WebP の中身を確認してから保存
  - `sync` で、どの実績にも使われていない写真を削除（取り下げ）。中身が変わらないときは書き込まない（KV の無料枠の節約）
- `gas/site-sync.gs`
  - 列は見出しの名前で読む（フォームに質問を足して列の位置が変わっても動く）
  - 写真はドライブの縮小画像（長辺1600px）を使うので、撮影場所などの情報はサイトに出ない。写真の名前はドライブのファイルIDから作るハッシュで、元のIDは公開しない
  - 1回の反映で写真の処理は約4.5分まで。残りは次の反映で送る（その行は「写真を準備中」）
- サイト（`assets/js/site.js`）
  - `/api/results`・`/api/coupons` を優先し、取れなければ `data/*.json` を表示
  - `config.js` の `keepSampleResults: true` のあいだは、掲載した実績の下にサンプルの実績も並べる（本番前に `false` に）
- メール送信の上限は関係しない（このスクリプトはメールを送らない）。Apps Script の1日の上限：外部への通信 20,000回（無料 Gmail）
